Alojamiento HTML gratuito

Pega tu HTML. Obtén una URL.

Crea URL aloja archivos HTML estáticos: pega el código o suelta un archivo, publica y recibe al instante un enlace limpio para compartir y un código QR. Sin git, sin repositorio y sin pipeline de despliegue.

Publicar una página Ver el stack

Cómo se usa

De HTML a URL en unos segundos. No necesitas cuenta para empezar.

  1. Escribe, pega o sube tu HTML

    En el editor pega el código completo de tu página, o usa una de las plantillas del menú superior como punto de partida. Escribe un título para identificarla en tu panel. El indicador de tamaño muestra cuánto ocupa frente al límite de tu cuenta.

  2. Revisa la vista previa

    A la derecha ves el resultado en un entorno aislado (sandbox). Cambia entre vista de escritorio, tablet y móvil, recarga la vista o ábrela en una pestaña nueva. El borrador se guarda automáticamente en tu navegador.

  3. Ajusta las opciones (opcional)

    En «Configuración de URL y Seguridad» puedes elegir un slug personalizado (por ejemplo mi-proyecto-web), proteger la página con contraseña (requiere cuenta) o activar el modo efímero, que la elimina al cabo de una hora. También puedes minificar el HTML, descargarlo como .html o exportarlo como .zip.

  4. Pulsa «Publicar Página Gratis»

    Se valida el marcado y se publica. Recibes la URL pública /p/tu-slug, un enlace directo al HTML (/raw/tu-slug), un código QR descargable y la fecha hasta la que estará disponible.

  5. Gestiona tus páginas desde el Panel de Control

    Allí ves tus páginas con su tamaño, visitas, fecha de caducidad y si están protegidas. Para cada una puedes copiar el enlace, verla, editar su contenido manteniendo la URL, consultar sus estadísticas de visitas, generar su QR, configurar o quitar la contraseña, prorrogarla 90 días o eliminarla. Las páginas que caducan pronto se resaltan con un aviso.

  6. Agrupa páginas en colecciones

    Crea una colección con título y descripción, añade tus páginas y comparte un único enlace /c/nombre: un portfolio, una muestra de prototipos o una entrega a un cliente.

Publicar desde un script

También puedes publicar por HTTP. Envía el HTML en el cuerpo de una petición POST /api/pages y recibirás la URL de la página en la respuesta.

curl -X POST https://crea-url.kbo1.workers.dev/api/pages \
  -H "Content-Type: application/json" \
  -d '{"title":"Mi página","html":"<h1>Hola</h1>"}'

Qué puedes hacer

Lo justo para compartir una página, sin complicaciones.

URL limpia al instante

Slug aleatorio o personalizado (3–40 caracteres) para que el enlace sea fácil de recordar.

Código QR

Genera y descarga el QR de cualquier página publicada para llevarla a una pantalla, un cartel o una diapositiva.

Colecciones

Agrupa varias páginas bajo un único enlace /c/nombre: un portfolio, una muestra de prototipos o una entrega a un cliente.

Protección con contraseña

Restringe el acceso a una página. La contraseña se guarda como hash, nunca en claro.

Modo efímero

Páginas de autodestrucción que desaparecen a la hora de publicarse. Ideales para compartir algo temporal.

Sandbox seguro

Cada página se sirve aislada con una política CSP de sandbox, de modo que el contenido no puede acceder a la aplicación.

Exportación ZIP

Descarga tu página en un paquete .zip cuando quieras llevártela a otro sitio.

Plantillas y validador

Empieza desde plantillas listas para usar y revisa el marcado antes de publicar.

Edición sin cambiar la URL

Modifica el contenido de una página ya publicada desde el panel. El enlace, el QR, la caducidad y la contraseña se mantienen.

Estadísticas de visitas

Gráfico de visitas por día (7, 30 o 90 días), visitas de hoy y de la última semana, y el mejor día. No se cuentan robots.

Avisos de caducidad

El panel destaca las páginas que caducan pronto y permite prorrogarlas todas de una vez.

API REST

Publica también por HTTP con POST /api/pages, útil para scripts y automatizaciones.

Preguntas frecuentes

Lo esencial sobre cómo funciona Crea URL.

¿Qué es Crea URL?

Una herramienta para poner un archivo HTML en internet en segundos: pegas el código o subes el archivo, publicas y obtienes un enlace compartible y un código QR.

¿Necesito registrarme?

No para publicar. Con cuenta gratuita el tamaño máximo sube de 1 MB a 10 MB, las páginas duran 3 meses en lugar de 15 días y puedes protegerlas con contraseña.

¿Cuánto tiempo permanece activa una página?

15 días si publicas de forma anónima y 3 meses con cuenta, con opción de prorrogar +90 días desde el panel. En modo efímero, la página desaparece pasada una hora.

¿Es seguro el contenido que publico?

Las páginas se sirven con una política de sandbox, de manera que no pueden acceder a la aplicación ni a datos de otros usuarios. Aun así, no publiques información sensible en páginas públicas.

¿Qué son las colecciones?

Una colección agrupa varias de tus páginas bajo un único enlace /c/nombre, con su propio título y descripción. Cada página sigue siendo independiente.

¿Puedo publicar desde un script?

Sí. La API acepta una petición POST /api/pages con el HTML en el cuerpo y devuelve la URL pública.

¿Qué ocurre cuando caduca una página?

Se elimina de forma automática, tanto el registro como el archivo almacenado. Puedes ampliar la caducidad antes de que ocurra.
