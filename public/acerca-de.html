Alojamiento HTML gratuito

Pega tu HTML. Obtén una URL.

Crea URL aloja archivos HTML estáticos: pega el código o suelta un archivo, publica y recibe al instante un enlace limpio para compartir y un código QR. Sin git, sin repositorio y sin pipeline de despliegue.

Publicar una página Ver el stack

De HTML a URL en 5 segundos

La forma más simple de publicar una página estática en internet.

  1. Pega o sube tu HTML

    Escribe en el editor, pega código o arrastra un archivo .html. No necesitas herramientas de compilación ni archivos de configuración.

  2. Pulsa «Publicar»

    Valida el marcado, opcionalmente lo minifica y lo guarda. Puedes elegir un slug personalizado, proteger la página con contraseña o hacerla efímera.

  3. Comparte el enlace

    Recibes una URL pública /p/tu-slug, un enlace directo al HTML (/raw/tu-slug) y un código QR descargable para presentaciones, demos o landing pages.

Qué puedes hacer

Lo justo para compartir una página, sin complicaciones.

URL limpia al instante

Slug aleatorio o personalizado (3–40 caracteres) para que el enlace sea fácil de recordar.

Código QR

Genera y descarga el QR de cualquier página publicada para llevarla a una pantalla, un cartel o una diapositiva.

Colecciones

Agrupa varias páginas bajo un único enlace /c/nombre: un portfolio, una muestra de prototipos o una entrega a un cliente.

Protección con contraseña

Restringe el acceso a una página. La contraseña se guarda como hash, nunca en claro.

Modo efímero

Páginas de autodestrucción que desaparecen a la hora de publicarse. Ideales para compartir algo temporal.

Sandbox seguro

Cada página se sirve aislada con una política CSP de sandbox, de modo que el contenido no puede acceder a la aplicación.

Exportación ZIP

Descarga tu página en un paquete .zip cuando quieras llevártela a otro sitio.

Plantillas y validador

Empieza desde plantillas listas para usar y revisa el marcado antes de publicar.

API REST

Publica también por HTTP con POST /api/pages, útil para scripts y automatizaciones.

Preguntas frecuentes

Lo esencial sobre cómo funciona Crea URL.

¿Qué es Crea URL?

Una herramienta para poner un archivo HTML en internet en segundos: pegas el código o subes el archivo, publicas y obtienes un enlace compartible y un código QR.

¿Necesito registrarme?

No para publicar. Con una sesión iniciada obtienes un límite de tamaño mayor (10 MB) y una duración más larga (90 días) además de la gestión de tus páginas.

¿Cuánto tiempo permanece activa una página?

15 días si publicas de forma anónima y 90 días con cuenta, con opción de ampliar la caducidad. En modo efímero, la página desaparece pasada una hora.

¿Es seguro el contenido que publico?

Las páginas se sirven con una política de sandbox, de manera que no pueden acceder a la aplicación ni a datos de otros usuarios. Aun así, no publiques información sensible en páginas públicas.

¿Qué son las colecciones?

Una colección agrupa varias de tus páginas bajo un único enlace /c/nombre, con su propio título y descripción. Cada página sigue siendo independiente.

¿Puedo publicar desde un script?

Sí. La API acepta una petición POST /api/pages con el HTML en el cuerpo y devuelve la URL pública.

¿Qué ocurre cuando caduca una página?

Se elimina de forma automática, tanto el registro como el archivo almacenado. Puedes ampliar la caducidad antes de que ocurra.
